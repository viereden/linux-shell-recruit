1. 当输入 `./tools/recruit-info` 时，这是绝对路径。Shell 不需要去查找 PATH 变量，它直接根据路径地址去定位文件，而如果拥有执行权限就可以运行该文件。只输入` recruit-info `时，这是程序名而不包括路径。Shell 会根据 PATH 环境变量中配置保存的目录依次查找。因为`recruit-info`在tools目录而 tools 目录不在当前的 PATH 环境变量中，所以 Shell 找不到这个命令，于是就会报错 command not found。关键点:是否给出路径使shell以此定位文件。给出完整路径，就能够直接定位；只给程序名，依旧用PATH寻找。
2. ls是一个标准系统命令，存放于`bin`等被PATH环境变量包含的标准路径。所以输入ls时，shell会从PATH的各个目录里寻找，发现名字为ls的文件，如果可执行就会执行。
